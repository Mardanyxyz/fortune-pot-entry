An entry for make.fun's "Fortune in a Pot" bounty: a program that writes one
kind, funny fortune for the houseplant on the windowsill — a single line of at
most 120 characters — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

It needs Node 22 or later, uses only the standard library, makes no network
calls, and always writes the same line. Read the fortune with:

```sh
cat /output/entry.txt
```
